# 던전 웹 브라우저 수동·자동 조작 QA — 2026-09-11

## 후속 수정 및 재검증

아래에서 발견한 세 문제는 후속 수정 후 실제 브라우저에서 재확인했다.

- 단층 생성은 1층으로 유지하면서 기존 `floor_count`와 진행 방향을 보존한다.
  실프주식회사에서 2~3층 → 단층 → 여러 층을 전환해 범위 보존을 확인했다.
- NBT 자동 생성에서는 `continuous`와 `authored` 층 옵션을 미지원으로 표시하고
  비활성화했다. 기존 문서에 해당 조합이 있으면 다른 알고리즘으로 대신 그리지 않고
  미지원 사유를 안내한다. 별도 층 생성 알고리즘을 새로 구현한 것은 아니다.
- NPC 배치 요약은 실제 배정 수/요구 인원을 표시한다. 시드 7, 단층, 최소 간격 100에서
  `5/7명 배치 · 7자리 필요 / 36개 후보 슬롯` 및 2자리 부족 안내를 확인했다.
- 기존 생성 회귀 360건에 층 범위 보존·미지원 모드·실제 인원 표시 검사를 추가했다.
  브라우저 콘솔 오류는 없었으며 테스트 입력은 저장하지 않았다.

## 범위와 방법

- `http://127.0.0.1:8765`의 실제 콘텐츠 편집기를 임시 브라우저 탭에서 조작했다.
- 컴퓨터 사용 스킬을 참고하고 브라우저 제어 도구로 폼, 선택창, 버튼, 키보드를 조작했다.
- 페이지의 표시값·오류 안내·스크린샷·브라우저 콘솔을 확인했다. 앱 내부 상태를 주입하거나
  생성 함수를 직접 호출한 결과를 브라우저 테스트로 계산하지 않았다.
- 던전 저장 버튼을 누르지 않았다. 콘텐츠·구현 코드는 수정하지 않았으며,
  인게임 실행 및 서버/웹 생성 결과의 일치는 이번 검증 범위가 아니다.

## 확인된 문제

### 1. 단층 전환 후 기존 다층 범위 소실

1. 카지노 또는 실프주식회사의 기본 다층 설정(최소 2, 최대 3)을 연다.
2. 층 구조를 `단층`으로 변경한다.
3. 다시 `여러 층 + 계단`으로 변경한다.
4. 상세 생성 옵션의 층 수가 `1~1`이고 미리보기도 1층으로 남는다.

다층 범위를 보존하거나 복원해야 하며, 적어도 사용자가 다시 층 수를 지정해야 한다는
안내가 필요하다. 최소·최대 층 수를 직접 3으로 지정하면 3층 생성과 층별 조회는 정상이다.

### 2. 층 구조의 서로 다른 옵션이 같은 생성 결과를 표시

실프주식회사 기본 설정에서 시드 `7`을 실제 키보드로 입력하고 아래 옵션을 순서대로 변경했다.

| 층 구조 | 미리보기 결과 |
| --- | --- |
| 여러 층 + 계단 (`discrete_floors`) | 2층, 구획 47, 일반 공동 4, 경계 336×16×256 |
| 자연스러운 높이 변화 (`continuous`) | 동일 |
| 직접 배치 (`authored`) | 동일 |

세 경우 모두 `compiled-floors`, 이벤트 좌표도 동일했다. 직접 배치 선택 후에도
계획 방식은 `runtime`, 계획 예시는 `시드 계획 1`이었다. 옵션별 구현을 연결하거나,
현재 지원하지 않는 조합을 비활성화하고 이유를 알려야 한다.

### 3. NPC 배치 실패 시 요약의 배치 인원 과장

1. 실프주식회사, 단층, 시드 `7`을 사용한다.
2. NPC 최소 간격을 `100`으로 변경한다(의도적으로 배치 불가능한 조건).
3. 하단에 유효한 마커 2개 부족으로 컴파일 불가 안내가 나온다.
4. 실제 이벤트 목록의 `NPC 자리`는 5개인데 요약은
   `7명 배치 · 7자리 필요 / 36자리 생성`이라고 표시한다.

필요 인원과 실제 배치 인원을 구분해야 한다. 예: `5/7명 배치`.
최소 간격을 4로 복원하면 실패 안내가 사라지는 것은 확인했다.

## 정상 동작 확인

아래 정상 생성 조합 41건에서는 화면의 연결·중첩·NPC 용량 관련 오류 안내가 없었다.
이는 해당 시드의 웹 표시 검사이며 모든 시드나 실제 블록 보행 가능성을 보증하지 않는다.

| 분류 | 건수 | 조건 |
| --- | ---: | --- |
| 카지노 3층 진행 구조 | 12 | 공동 분산형/중앙 복도형 × 선형/분기/순환/목표 후 보스/열쇠/지름길 |
| 공동 단독 선택 | 18 | 1×2/2×2 × 1인/독립행동/협력 × 새 시드 3회 |
| 다른 스킨 프리셋 | 8 | 포켓몬타워/실프주식회사 × 새 시드 4회 |
| 협동 NPC 증감 | 3 | 2×2 공동만 선택, 자동 조우 1/3/12쌍 |

추가 확인:

- 공동 검색창에 1×2는 NPC 2, 2×2는 NPC 4로 표시된다.
- 3층 고정 생성 후 1층/2층/3층/전체 조회에서 표시 구획 수가 바뀐다.
- 자동 NPC 생성을 끄면 보스만 남는 배치 용량으로 다시 계산한다.
- 실프주식회사에서 실제 키보드 입력으로 시드 7→42→7을 적용했을 때
  최초 시드 7의 지형 지표와 이벤트 목록이 동일하게 재현됐다.
- 발전소 고정 NBT 검색창에서 크기·입구/출구·보스·콘텐츠 슬롯이 표시된다.
  없는 검색어와 최소 슬롯 11 조건에서는 적절한 결과 없음 안내가 표시된다.
- 썬더 자연동굴에서 보스·전리품 이벤트가 지도에 표시된다.
  자동 배치를 수동 편집으로 전환하고 입구를 선택하면 X/Y/Z를 편집할 수 있다.
- 자연동굴→발전소→실프주식회사 전환 후 동굴 편집기는 숨겨지고 NBT 미리보기만 표시된다.
- 마지막 확인까지 브라우저 콘솔 error/warn은 없었다.

## 검증 과정에서 정정한 항목

초기에 자동 입력 `fill` 후 시드가 적용되지 않는 것으로 보였으나, 실제 키보드 입력으로
재검증하니 정상 반영됐다. 이를 앱의 확정 버그로 분류하지 않는다.
이 초기 시드 입력 시도 12건은 위 정상 생성 조합 41건에 포함하지 않았다.
