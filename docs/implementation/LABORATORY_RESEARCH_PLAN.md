# 연구소 서비스 구현 계획

2026-09-09. 기술머신 제작은 별도 작업에서 다룬다. 아래 금액·수량을 첫 기본값으로
구현했다. 빌드·배포된 모드가 콘텐츠 설정을 읽어 적용하며 이후 밸런스 조정이 가능하다.
사용자 추가 결정: 기존 모드 제작법을 따를 필요 없이 모든 연구소 서비스에
독립적인 제작법·비용을 설정한다. 기존 레시피는 아이템 확인용 참고 자료다.

## 확정된 흐름

- Z기술: 대화 → 현재 파티 → 현재 기술·종·폼 조건으로 크리스탈 후보 표시
  → 재료 확인·제작 → 바로 지니게 할지 확인. 전용 Z기술은 필수 원본 기술까지 검사한다.
- 메가진화: 파티 전체에 가능/불가능과 사유 표시 → 포켓몬 → 지원되는 진화 형태
  → 재료 확인·메가스톤 제작 → 바로 지니게 할지 확인.
- 다이맥스: 파티 → 현재/목표 레벨, 거다이맥스 지원 여부와 인자 보유 상태 표시
  → 다이버섯 소비로 조절. 획득처는 향후 레이드덴 모드에서 처리하며 지금은 추가하지 않는다.
- 능력치: 현재 파티 → 여섯 능력치 현재/목표값 편집 → 변경 내역·총액 → 일괄 적용.
  기존 음식 사용은 유지한다. 수치를 내리는 것은 무료이고 올리는 것만 과금한다.
- 포켓몬 선택 UI는 가방 아이템 사용·지니게 하기·키우미집·연구소에서 공유한다.

## 비용 초안

| 서비스 | 재료 / 비용 | 예시·비고 |
| --- | --- | --- |
| 일반 Z크리스탈 | 빈 Z크리스탈 1 + 해당 속성 젬 3 | 같은 타입 기술은 한 후보로 묶음 |
| 전용 Z크리스탈 | 빈 Z크리스탈 1 + 전용 Z기술 타입 젬 5 | 종·폼·필수 기술 충족 필요 |
| 메가스톤 | 미가공 메가스톤 1 + 연구비 5,000원 | X/Y/Z 등 형태별 동일 비용 |
| 다이맥스 레벨 상승 | +1당 다이버섯 1 | 0→10은 10개 |
| 다이맥스 레벨 하락 | 무료 | 0~10 범위, 환급 없음 |
| 거다이맥스 인자 부여 | 다이버섯 3 | 지원 종·폼만, 이미 보유하면 과금하지 않음 |
| 거다이맥스 인자 제거 | 무료 제안 | 재부여에는 다시 3개 필요 |
| 개체값 상승 | +1당 500원 | 한 능력치 0→31은 15,500원 |
| 노력치 상승 | +1당 10원 | 한 능력치 0→252는 2,520원 |
| 개체값·노력치 하락 | 무료 | 환급 없음 |

능력치별 `max(0, 목표값 - 현재값)`을 합산해 비용을 계산한다. 감소분으로 다른
능력치 상승분을 상쇄하지 않는다. 개체값은 각 0~31, 노력치는 각 0~252·총합 510을
기본으로 하되 서버의 실제 제약과 일치하는지 확인한다. 6개 개체값 0→31은 93,000원,
노력치 총 0→510은 5,100원이다. 재설정한 수치가 실제 전투 계산에도 적용되어야 한다.

위 비용은 키우미집의 5분 훈련 100원과 비교할 수 있도록 예시를 명시한 초안이다.
레이드 드롭 빈도·젬 공급량·트레이너 보상 수입에 맞춰 출시 전 조정한다.
비용은 서버 콘텐츠 설정으로 분리하고 화면에 하드코딩하지 않는다.

## 실제 의존성 확인

로컬 `.tmp/cobblemon-1.8-addon-audit/mega-showdown-beta2.jar`의 영문 번역과
`data/mega_showdown/recipe`를 직접 읽어 확인했다. 최종 서비스는 이 임시 JAR 경로에
의존하지 않고 현재 서버의 아이템 레지스트리·기믹 정의를 사용한다.
재료·비용은 연구소 전용 설정에서 읽으며 기존 조합법을 자동 복제하지 않는다.

- 빈 Z크리스탈: `mega_showdown:blank_z` (Blank-Z).
- 미가공 메가 재료: `mega_showdown:mega_stone` (Mega Stone).
- 다이버섯: `mega_showdown:max_mushroom` (Max Mushroom).
- 참고용 기존 리자몽나이트 X: 메가 재료 1 + `cobblemon:dragon_fang` 1 + 철괴 2 + 다이아몬드 1.
- 참고용 기존 리자몽나이트 Y: 메가 재료 1 + `cobblemon:charcoal_stick` 1 + 철괴 2 + 다이아몬드 1.
- 기존 다이수프: 다이버섯 3 + 그릇 1. 연구소 인자 부여에 3개를 쓰는 초안의 참고값이다.
- 해당 JAR에는 루카리오나이트 Z 등 추가 형태도 있다. X/Y만 고정 열거하지 않는다.

돌을 요구하지 않는 메가진화 예외와 데이터팩 추가 형태는 조건별로 구분한다.
기존 조합법이 없어도 실제 아이템·진화 정의와 연구소 전용 제작 설정이 있으면
제작할 수 있다. 존재하지 않는 아이템이나 미지원 진화 형태를 후보로 만들지 않는다.
기존 조합법과 다이버섯의 다른 획득 경로 제거는 아직 요청되지 않았으므로 유지한다.
레이드 보상 연결은 향후 레이드덴 모드 도입 작업에서 다룬다. 현재 별도 획득처는 추가하지 않는다.

## 공용 포켓몬 선택창

소유 모듈은 `cobbleventure-player-menu`이다. `PokemonSelectScreen`이 모델·카드,
파티 배치, 가능/불가능 설명, ESC/뒤로 가기와 공통 테마를 관리한다.

호출자는 다음을 제공한다.

- 부모 화면, 제목, 안내문, 선택적 아이콘.
- `Entry(slot, pokemon)` 목록 공급자: 일반 파티 또는 서버가 보낸 스냅샷.
- 포켓몬별 `Eligibility(selectable, label, hint)` 판정.
- 선택 후 콜백: 다음 화면을 열거나 원래 화면으로 돌아가는 것은 호출자 책임.

일반 가방은 기존 HP·경험치·지닌 물건을 표시한다. 기술머신과 연구 기능은
상태 문구로 교체할 수 있다. 가방의 기술머신 제작·학습 정책은 변경하지 않는다.
선택 직전에 슬롯과 UUID를 다시 대조하고, 목록의 UUID/슬롯 변경 시 다시 구성한다.
서버도 UUID·소유권·파티 상태·서비스 이용 자격을 검증해야 한다.

키우미집은 보관 포켓몬·요금·훈련 설정을 표시하는 관리 화면을 유지한다.
파티 패널의 포켓몬 선택 버튼이 공용 선택창을 연다. 기존 그리드 직접 선택도 가능하다.
선택창에서 돌아올 때 서버 스냅샷의 UUID도 비교하며, 키우미집 응답은 부모 관리 화면으로
전달해 선택창을 덮어쓰지 않는다.

## 거래·상태 검증

- 화면에서는 견적만 계산하고 서버 확정 시 현재 기술, 폼, 재료, 돈, 목표값을 다시 검사한다.
- 취소·잔액 부족·재료 부족·조건 변경에는 차감하지 않는다. 중복 확정 요청도 한 번만 처리한다.
- 배틀 중 사용 제한과 NPC 대화 세션·거리 검증은 기존 시설 서비스 기준을 따른다.
- 제작물 수령 공간을 확인한다. 장착 교체 시 기존 물건 반환 공간이 없으면 교체를 막는다.
- 제작과 장착은 구분한다. 제작 후 장착 취소는 완성품을 가방에 남긴다.
- 다이맥스 레벨과 거다이맥스 인자는 실제 포켓몬 저장 데이터와 전투 어댑터가 함께 읽어야 한다.
- 능력치 조절 후 능력치·현재 HP의 일관성, 저장·재접속 유지, 전투 반영을 검증한다.

## 구현 위치와 배포

- `projects/cobbleventure-adventure/.../research`: 서버 세션, 후보 카탈로그, 거래 처리, 연구 화면.
- `content/catalogs/laboratory-research.json`: 비용, 재료, Z크리스탈 조건, 다이맥스 제외 종.
- 콘텐츠 관리 **전역 리소스 → 연구소 비용·제작 설정** (`/research.html`): 비용·재료 입력과 조건 JSON 편집.
- Adventure `processResources`가 설정을 `data/cobbleventure_adventure/research/settings.json`으로 패키징한다.
- 서버는 일반 인벤토리와 확장 가방을 모두 재료로 검색한다. 완성품과 이전 지닌 물건은 확장 가방에 보관한다.
- 연구 세션은 10분, NPC 거리 8블록 이내이며 배틀 중에는 사용할 수 없다.
- 요청 토큰은 처리 전에 소모하고 응답마다 갱신한다. 포켓몬의 종·폼·기술·능력치·다이맥스
  상태가 달라졌으면 새 상태를 보여주고 다시 확인받는다.
- 능력치 조절은 실제 IV/EV를 수정하며 기존 대단한특훈 보정도 목표값으로 정리한다.
- 메가 후보는 현재 데이터팩의 `mega_showdown/mega` 정의와 실제 등록 아이템을 읽는다.
  Z 조건 35개(일반 18·전용 17)는 로컬 Showdown `data/items.js`와 `data/moves.js`,
  Mega Showdown의 `z_crystal_item` ID를 대조한 초기 카탈로그다. 새 전용 Z기술 추가 시 편집기에서 확장한다.
- 배포 시 player-menu와 adventure JAR 및 NPC/건물 콘텐츠를 함께 빌드한다. 기존 월드에서
  이미 생성된 내부는 자동 교체되지 않을 수 있으므로 새 연구소 인스턴스로 먼저 확인한다.
