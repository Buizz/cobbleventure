# Cobblemon 1.8.0 기본 기술머신 제작 데이터

2026-09-09 조사. 로컬 정식 `Cobblemon-neoforge-1.8.0+1.21.1.jar`의 `data/cobblemon/tms/*.json` 335개를 집계했다. 서버 데이터팩이 덮어쓴 최종 목록이나 인게임 실행 결과는 아니다.

모든 항목에 제작법이 있다. `default` 128종, `unlockable` 206종, `advancement` 1종. 재료 식별자는 태그 6개를 포함해 총 115종이다. 모든 제작에는 아래 재료 외에 빈 기술머신 디스크가 필요하다.

메가드레인이 참조하는 `cobblemon:craft_remedy` 발전과제 정의는 조사한 JAR에 없다. 이 조건이 정상 작동한다고 해석하지 않도록 [후속 조사](COBBLEMON_1_8_TM_RESEARCH.md)를 함께 참고한다.
