# 건물 높이와 부지 확보

건물의 기본 높이 기준은 진입도로다. 마을 시설의 기존 도로 기준 배치에 더해, 중앙 배치 월드 오브젝트도 연결된 길의 입구 지점 높이를 사용한다. 건물 중심 X/Z와 회전은 유지한다. 연결된 길이 없으면 입구에서 한 타일 반경 내 가장 가까운 길을 찾고, 길 자체가 없으면 기존 지형 높이를 사용한다.

마커는 `road_anchor` 직소를 먼저 사용하고, 없으면 저장된 `door`, `transition`, 기존 던전의 `interaction_point` 순서로 찾는다. 실제 문 블록을 추측하지 않는다. 안전 도착점은 발 위치이므로 1블록 아래가 입구 노면이고, road_anchor는 그 자체가 노면이다. NBT의 로컬 입구 높이를 빼서 구조물 원점을 구한다.

NBT 설정의 `terrain_preparation`은 `none`(도로 기준 배치) 또는 `reserve_plot`(도로 기준 배치 후 부지 확보)이다. 추가 부지 확보는 월드 오브젝트 배치에 적용하며 석영고원에 활성화했다. NBT 사각형과 2블록 여백을 입구 노면 높이에 맞추고, 바깥 8블록은 원래 지형에 연결한다. 자연 지형과 식생을 정리하며 블록 엔티티·물·기존 석조 구조물은 삭제하지 않는다. 기존 생성 도로의 노면은 보정 높이로 옮긴다. NBT 자체는 변경하지 않고 지형 정리 후 배치한다. 아치는 같은 부지 높이 계획을 참조한다.

부지 정리는 생성 완료 표식이 없는 새 오브젝트에만 실행한다. 기존 건물이 있는 월드를 자동으로 철거·재시공하지 않는다. 지형 생성 후 부지 정리 방식이므로 실제 인게임 확인은 별도로 필요하다. 기초 범위를 별도 마스크로 지정하거나 마을 시설에 추가 부지 옵션을 적용하는 기능은 현재 범위에 포함되지 않는다.
