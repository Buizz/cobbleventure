# 화석 연구소

## 이용 흐름

- 실내 `npc3`는 복원 담당 연구원, `npc1`과 `npc2`는 상식을 설명하는 연구원이다.
- 담당 연구원의 CVES 설명 뒤 `open_fossil`이 전용 메뉴를 연다.
- 서버가 현재 Cobblemon 화석 레시피와 플레이어 인벤토리를 대조한다. 조각 화석은
  완성 가능한 조합만 표시하며, 재료가 겹치는 레시피도 같은 아이템을 중복 사용하지 않는다.
- 목록 선택 후 복원 버튼을 누르면 표시된 재료를 차감하고 메뉴를 닫는다.
- 연구원 근처의 실제 복원 기계가 약 30초 동안 가동된다. 배양 재료와 몬스터볼은
  연구소에서 제공한다. 완료 메시지 이후 연구원 메뉴에서 포켓몬을 받는다.
- 파티가 가득 차면 기존 Cobblemon 보관 로직으로 PC에 들어간다. PC도 가득 찼으면
  기계에 그대로 보관하고 공간 확보 후 다시 받을 수 있다.

## 상태와 호환성

`FossilLaboratoryService`는 수조 블록 엔티티의 NeoForge 영속 데이터에 의뢰자,
NPC, 레시피를 기록한다. 복원 상태와 투입 화석은 Cobblemon이 저장한다. 청크가
언로드되면 진행을 멈추고, 다시 로드하면 남은 진행을 이어 간다. 수령 전까지
기계는 다음 의뢰를 받지 않는다. 의뢰 중에는 직접 조작·파괴·폭발을 막는다.

Cobblemon 1.7.3과 1.8의 공통 필드에 접근하는 Mixin은 연구소 의뢰가 있는
기계에만 적용된다. 14,400틱의 진행 범위를 유지하면서 24배로 진행하고 10틱마다
화면 상태를 동기화하므로 기본 성장 모델, 기계 소리, 모니터 진행 표시를 사용한다.
개인이 운영하는 기계에는 시간 변경을 적용하지 않는다.

수령은 연구소 제공 몬스터볼로 원래 `useWithoutItem`을 호출한다. 기존 버전의
복원 이벤트·도전과제·색이 다른 포켓몬 처리와 1.8의 추가 알파 처리를 유지한다.
호출 중 플레이어 손의 아이템은 `finally`에서 복원한다.

## 검증

- 두 버전 각각 adventure `build`: 일반 회귀 테스트와 화석 재료 매칭,
  NPC 이벤트 어댑터, 설치된 JAR의 Mixin 필드·메서드 계약 검사.
- 콘텐츠 전체 validate와 generate, `test_fossil_laboratory.py`, CVES 파서·컴파일러,
  전역 UI 테마 계약 테스트.
- 실클라이언트 확인: 설명→메뉴→성장 연출→수령, 조각 조합, 연속 클릭,
  다른 플레이어 접근, 재접속·청크 재로드, 파티·PC 만석, 개인 기계 기본 시간 유지.

실클라이언트의 시각·음향 확인은 자동 빌드 및 단위 테스트와 별도로 수행한다.
