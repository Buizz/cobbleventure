# Cobbleventure Experience

Cobblemon 1.8용 독립 NeoForge 모듈이다. 다음 외부 모드의 팩 내 역할을 하나로
대체한다.

- Cobblemon EXP Bar
- Fix Cobblemon Pokemon Experience
- Cobblemon Capture XP 및 전용 Tim Core 의존성

## 동작

- 상대 포켓몬이 쓰러진 즉시 참가 포켓몬에게 전체 경험치를 지급한다.
- 비참가 포켓몬은 경험치 공유 아이템을 들고 있을 때 Cobblemon 설정 배율을 받는다.
- 레벨캡 전투 복사본으로 계산하더라도 경험치는 저장된 원본 포켓몬에 반영한다.
- 전투 중 포획은 실제 배틀 참가 정보와 Cobblemon 경험치 계산기를 사용한다.
- 필드 포획은 선두 생존 포켓몬과 경험치 공유 대상에게 표준 경험치 공식과
  교환·행복도·행운의알·진화 가능 보정을 적용한다.
- 경험치바는 내 포켓몬 전투 상태창 하단 프레임 안쪽에 전투 내내 표시한다.
  타입 아이콘 두 개의 공간을 비워두고 오른쪽에 2px 높이로 표시하며,
  하단 테두리와 간격을 두고 빈 게이지는 전역 테마의 어두운 색을 사용한다.
  Cobblemon이 계산한 실제 상태창 좌표를 사용하므로 교체 애니메이션과
  단일·더블 배틀의 일반/축소 상태창을 따라간다.
- 경험치 획득 패킷은 포켓몬 UUID로 연결해 같은 이름의 포켓몬도 구분한다.
  획득 알림이 없어도 동기화된 파티 데이터로 현재 경험치를 표시한다.
- 빈 막대는 Player Menu 전역 테마를, 경험치 채움은 Cobblemon 파티 상태창의
  파란 경험치 도메인 색상(#33A6D6)을 사용한다.
  상태창을 그린 뒤 표시하여 프레임에 가려지지 않는다.
- 경험치 애니메이션이 다음 레벨에 도달하면 해당 상태창 전체가 0.65초 동안
  최대 8% 확대되었다가 복귀하고, 원본 프레임에 밝은 발광 효과를 겹친다.
  일반 경험치 획득에는 발광하지 않으며 포켓몬 UUID별로 연출을 구분한다.
- 전투 경험치바가 차오를 때 Cobblemon 파티 UI의 `gui.levelup_start`를,
  레벨업 순간에는 `gui.levelup`을 재생한다. 동시 획득은 소리 하나로 합치고
  게이지 숨김·전투 종료·로그아웃 때 채움 소리를 정지한다.
  특정 본가 작품의 음원을 별도로 추가한 것은 아니다.

## 포획 경험치 분배 확인

기존 Capture XP 1.7.3 계열 JAR의 두 포획 핸들러와 기본 설정을 확인했다.
전투 중에는 생존 참가자와 학습장치 소지자, 필드에서는 첫 생존 포켓몬과
학습장치 소지자가 받는 것이 기존 기본 동작이다. 방금 잡힌 포켓몬은 제외한다.
따라서 학습장치 없는 비참가 파티원이 경험치를 받지 않는 것은 이 규칙에 부합한다.
기존 모드의 전체 공유는 기본값이 꺼진 별도 옵션이며 Tim Core의 EXP All 판정도
필요했다. 자체 모듈은 그 선택 기능을 구현하지 않는다.

HUD 패킷 형식이 버전 2로 변경되었으므로 서버와 클라이언트의 이 모듈을 함께
갱신해야 한다.

## 빌드

저장소 루트에서 다음 명령을 사용한다. 공통 UI JAR도 먼저 갱신된다.

```bat
build.bat mod-experience
```

완성 JAR은 `pack/overrides/development-1.8/mods`에 설치된다.

## 인게임 회귀 확인

1. 야생 및 트레이너전에서 첫 KO 직후 경험치가 오르고 종료 때 중복 지급되지 않는지 확인한다.
2. 교체 전투에서 실제로 상대를 마주친 포켓몬과 경험치 공유 대상만 보상받는지 확인한다.
3. 레벨캡보다 높은 포켓몬이 전투한 뒤 원본 포켓몬의 경험치가 유지되는지 확인한다.
4. 전투 포획과 필드 포획에서 잡은 포켓몬 자신은 보상 대상에서 빠지는지 확인한다.
5. 경험치를 얻기 전부터 내 전투 상태창 하단 안쪽에 막대가 표시되는지 확인한다.
6. 단일·더블 배틀, 포켓몬 교체와 여러 GUI 배율에서 막대가 해당 상태창을 따라가는지 확인한다.
7. 같은 이름의 포켓몬 두 마리, 연속 획득과 레벨업에서 각 막대가 올바르게 갱신되는지 확인한다.
